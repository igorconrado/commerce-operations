## Portfolio gaps and approval gates

- Real LLM/tool comparison and subjective human rubric scores are **not run**.
  Provider/model/budget configuration and real reviewer input are required.
- AWS is written and statically validated, not provisioned/deployed. Paid resources
  and any public endpoint require approval. The [costed proposal](runbooks/aws-proposal.md)
  estimates USD 40–50/month under its stated assumptions.
- Commerce optimization is a measured repository microbenchmark; a sustained HTTP
  saturation study with full database/host resource sampling remains planned.
- Workbench external HTTP sandbox isolation, durable lifetime quotas and cursor
  pagination remain hardening work. Neither project claims general safety or HA.
- [GitHub profile copy](profile-proposal.md) is prepared, not applied to the public profile.
